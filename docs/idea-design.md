# 아이디어 설계

## 문제 정의

서울에 거주하거나 서울 생활권에 있는 예비·신혼부부는 자신에게 적용되는 정책이 존재하더라도, 정책이 결혼, 주거, 금융, 세금, 돌봄 영역별로 분산되어 있고 기준 시점과 조건이 서로 달라 어떤 정책을 언제 어떤 순서로 신청해야 하는지 판단하기 어렵다.

이 문제는 단순히 지원 정책을 검색하기 어렵다는 수준보다 복잡하다. 사용자는 정책 목록이 아니라 상황별 판단과 실행 순서를 필요로 한다.

## 사용자가 판단해야 하는 질문

- 지금 혼인신고를 하는 것이 유리한가?
- 결혼 예정자 자격으로 먼저 신청할 수 있는가?
- 서울 거주 기간 조건을 충족하는가?
- 부부합산 소득은 어떤 연도를 기준으로 하는가?
- 전세 계약 전과 후 중 언제 신청해야 하는가?
- 다른 주거 지원과 중복 이용할 수 있는가?
- 결혼식 지원과 살림비 지원을 함께 받을 수 있는가?
- 출산 전 신청해야 하는 혜택은 무엇인가?
- 아이가 태어난 뒤 자동으로 이어지는 정책은 무엇인가?
- 맞벌이 여부에 따라 돌봄 지원이 달라지는가?

## 서비스 목표

서울시 공공정책 정보를 신혼부부의 생애 흐름에 맞춰 통합적으로 제공한다. 사용자가 자신의 상황을 대화로 입력하면, 서비스는 정책 후보, 충족 조건, 미확인 조건, 탈락 가능 조건, 다음 행동을 그래프와 챗봇으로 설명한다.

## 대상 사용자

- 서울 거주 예비부부
- 서울 전입 예정 예비부부
- 혼인 초기 신혼부부
- 주거, 대출, 웨딩, 세제, 출산·육아 정책을 함께 검토해야 하는 사용자

## 정책 분야

MVP에서는 다음 5개 분야를 선제시한다.

- 주거
- 대출
- 웨딩
- 세제
- 출산·육아

## 핵심 차별점

| 기존 방식 | 한계 | 제안 서비스의 차별점 |
| --- | --- | --- |
| 정책 검색 | 사용자가 검색어를 알아야 함 | 생활 상황을 대화로 파악 |
| 조건 필터 | 조건을 사용자가 해석해야 함 | 조건 충족·미확인 이유 설명 |
| 정책 목록 | 여러 정책이 나열됨 | 신청 우선순위 제공 |
| 개별 신청 | 정책마다 별도로 이동 | 신청 링크·서류·일정 연결 |
| 단일 시점 추천 | 상황 변화 반영이 어려움 | 혼인·전입·출산 변화에 따라 재평가 |
| 일반 혜택 안내 | 신혼 과정에 특화되지 않음 | 결혼부터 돌봄까지 생애 흐름 관리 |

## 제품 방향

서비스는 단순 검색 서비스가 아니라 정책 판단 보조 도구다. 따라서 MVP는 많은 정책을 한 번에 수집하기보다, 적은 수의 정책이라도 조건과 신청 순서를 설명 가능한 구조로 제공하는 것을 우선한다.
