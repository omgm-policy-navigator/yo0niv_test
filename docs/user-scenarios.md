# 사용자 시나리오

## 전체 사용자 흐름

### 1단계: 분야 선택

사용자는 먼저 관심 정책 분야를 선택한다.

```text
주거 / 대출 / 웨딩 / 세제 / 출산·육아
```

### 2단계: 핵심 질문

선택한 분야에 맞는 핵심 질문 3~5개를 순서대로 제시한다.

예시:

- 혼인신고를 하셨나요?
- 두 분 모두 무주택인가요?
- 서울에 거주하거나 전입 예정인가요?
- 소득 구간은 어떻게 되시나요?

### 3단계: 1차 그래프 생성

사용자의 초기 응답을 바탕으로 정책 후보와 확인이 필요한 조건을 그래프로 보여준다.

```text
사용자
→ 선택 분야
→ 정책 후보
→ 확인이 필요한 조건
```

### 4단계: 추가 질문

그래프에서 `확인 필요` 상태인 조건만 추가로 질문한다. 이미 확인된 조건은 다시 묻지 않는다.

예시:

```text
자녀가 있다고 응답한 경우에만
자녀 생년월일 질문 표시
```

### 5단계: 그래프 재생성

추가 답변을 반영해 정책 후보 상태를 갱신한다.

```text
가능성 높음
추가 확인 필요
특정 시점 이후 가능
가능성 낮음
```

### 6단계: 정책 노드 선택

사용자가 정책 노드를 선택하면 챗봇이 정책 상세, 신청 방법, 필요 서류, 공식 링크를 설명한다.

### 7단계: 신청 로드맵

정책별 신청 순서를 행동 노드로 보여준다.

```text
지금 확인
→ 계약 전 신청
→ 서류 준비
→ 공식 신청
→ 결과 확인
```

### 8단계: 저장과 알림

사용자는 관심 있는 정책만 저장하고 신청 마감 또는 재평가 시점 알림을 받을 수 있다.

## 대표 시나리오: 서울 전입 예정 예비부부

1. 사용자가 `주거`와 `대출` 분야를 선택한다.
2. 챗봇이 혼인 예정 여부, 무주택 여부, 서울 거주 또는 전입 예정 여부를 질문한다.
3. 서비스는 신혼부부 임차보증금 이자지원과 관련 대출 정책 후보를 그래프에 표시한다.
4. 서울 거주 기간이 미확인 조건으로 표시된다.
5. 사용자가 전입 예정일을 입력한다.
6. 서비스는 현재 신청 가능 정책과 전입 이후 재평가해야 하는 정책을 구분한다.
7. 사용자는 계약 전 확인해야 할 정책을 저장하고 알림을 설정한다.

## 대표 시나리오: 혼인신고 전 세제 혜택 검토

1. 사용자가 `세제` 분야를 선택한다.
2. 챗봇이 혼인신고 여부와 예정일을 질문한다.
3. 서비스는 혼인신고 이후 재평가가 필요한 정책을 표시한다.
4. 정책 관계 그래프에서 `혼인신고 → REEVALUATE_AFTER → 결혼세액공제` 관계를 보여준다.
5. 사용자가 결혼세액공제 노드를 선택하면 공식 기준일과 확인해야 할 서류를 설명한다.
